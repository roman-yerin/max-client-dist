MAX в терминале▊

max-client — это чат MAX в вашем шелле: окна бесед в стиле irssi, боты с кнопками, файлы из drag-and-drop и сквозное шифрование по команде /enc.

zsh
$curl -fsSL https://max.bythe.net/install.sh | bash
бинарник под вашу ОС и архитектуру ставится в ~/.local/bin

что внутри

  • окна, как в irssi
    десяток бесед одновременно, Ctrl+1…0, список по Ctrl+L, статус-бар с непрочитанными.
  • боты с кнопками
    инлайн-клавиатуры рендерятся, /btn N жмёт кнопку через opcode 118, ссылки открываются в браузере.
  • e2ee — /enc on
    X25519 + AES-256-GCM прямо в чате: рукопожатие текстом, ключи в ~/.max-cli, 🔒 в заголовке окна.
  • файлы и медиа
    drag-and-drop в терминал отправляет фото/видео, ссылки на медиа резолвятся автоматически.
  • без рекламы*
    персональный ed25519-ключ отключает HADS-карточки: /key КЛЮЧ — один раз и навсегда.
  • живёт при обрывах
    сам переподключается с backoff, восстанавливает окна и подписки, ходит через прокси.

первые шаги

maxзапуск; при первом входе — номер телефона и код из SMS
/msg +7999…открыть диалог по номеру
/enc on · /enc offвключить/выключить шифрование в текущем окне
/send /путьотправить файл
/helpполная справка

сборка

Го, всё локально: go build -o max ./cmd/max. Кросс-сборки и релизы — в GitHub Actions, бинары под darwin/linux (amd64+arm64) прикладываются к каждому тегу v*.
